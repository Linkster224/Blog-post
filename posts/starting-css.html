My First Day Learning CSS

July 24, 2026

Recently, I started learning CSS to understand how to style websites and make them more visually appealing. At first, it was a little confusing figuring out selectors, properties, and how everything connects, but as I practiced more, it started becoming easier. Learning the basics like colors, fonts, margins, and padding helped me understand the foundation of web design.

As I continued learning CSS, I began creating my own small projects and experimenting with different designs. I learned how to organize code properly, add navigation between pages, and make websites that are more interactive and enjoyable to use. Building my own websites has been a fun way to improve my skills while also being creative.

Learning CSS has motivated me to continue exploring web development and learn more advanced technologies like JavaScript. I enjoy seeing my ideas turn into real websites and improving each project as I gain more experience. This is just the beginning of my journey, and I’m excited to keep learning and creating new things.
